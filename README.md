# Aakriti Singh — Personal Portfolio

A modern, responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Included
- Responsive navigation
- Hero section
- About section
- Skills
- Project showcase
- Experience timeline
- Contact section
- Light/dark mode
- Scroll reveal animations
- Mobile navigation
- Cursor glow effect

## Run locally
1. Extract the folder.
2. Open `index.html` in a browser.
3. For the best development experience, open the folder in VS Code and use the Live Server extension.

## Personalize before publishing
Open `index.html` and update:
- Email address: replace `your.email@example.com`
- LinkedIn URL
- Project links currently set to `#`
- Project descriptions if you want different wording
- Add your own profile photo if desired

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Go to repository Settings → Pages.
4. Under Build and deployment, select `Deploy from a branch`.
5. Select the `main` branch and `/root`.
6. Save.
7. GitHub will provide your live portfolio URL.
